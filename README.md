# 反直觉博物馆

可亲手操作的认知偏差与概率悖论互动展馆。每件展品的参观流程:
**先押上直觉预测 → 亲手跑蒙特卡洛模拟 → 「你猜的 vs 实际发生的」对比 → 分层解释**(直觉版 / 数学版 / 现实案例)。

全部运算在浏览器完成,纯静态站点,无后端、无数据库。「直觉得分」存在 localStorage。

## 技术栈

Next.js (App Router, `output: "export"`) + TypeScript + Tailwind CSS v4,Vitest 做统计正确性测试。可直接部署到 Vercel。

```bash
npm install
npm run dev    # 本地开发
npm test       # 模拟函数收敛性测试(对照理论值)
npm run build  # 静态导出到 out/
```

## 统计正确性

每个展品的模拟逻辑是 `lib/sims/` 下与 UI 完全分离的纯函数,`tests/sims.test.ts`
用大样本(10 万~300 万次)断言模拟结果收敛到解析理论值(蒙提霍尔 2/3、生日悖论 50.7%、
基率谬误 1.94%、HHT/HTH 等待 8/10 次、秘书问题 37.1% ……)。文案中的所有数字与理论值一致。

## 新增展品

1. 在 `lib/sims/` 写纯函数模拟 + 在 `tests/` 加收敛性测试;
2. 在 `exhibits/meta.ts` 登记元数据(id / 展厅 / 标题 / 引子);
3. 新建 `exhibits/<id>.tsx`:预测选项 + Simulator 组件 + 三层解释;
4. 在 `exhibits/index.ts` 追加一行注册。

## 15 件展品

概率厅:蒙提霍尔、生日悖论、赌徒谬误、硬币模式等待时间、两个孩子问题、双信封问题
统计厅:辛普森悖论、幸存者偏差、本福特定律、均值回归、大数 vs 小数定律、伯克森悖论
决策厅:基率谬误、秘书问题(37% 法则)、等车悖论(检验悖论)
